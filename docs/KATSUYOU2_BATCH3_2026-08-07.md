## 会う
確認済み: `あわなかった / あえる / あえば / あおう / あわせる`

- なかった: きのうは いそがしくて、ともだちに あわなかった。
- 可能: らいしゅうなら、ともだちに あえる。
- ば: えきで あえば、いっしょに いけます。
- 意向: しゅうまつに ひさしぶりに ともだちに あおう。
- 使役: ははは こどもを せんせいに あわせる。

注意: `会わせる` は「会う」の使役として成立する一方、「人と人を引き合わせる」という語彙的な読みも強いため、使役関係が読み取れる文脈を使う。

## 歩く
確認済み: `あるかなかった / あるける / あるけば / あるこう / あるかせる`

- なかった: あめだったので、えきまで あるかなかった。
- 可能: この きょりなら、あるける。
- ば: えきまで あるけば、20ぷん かかります。
- 意向: てんきが いいから、えきまで あるこう。
- 使役: せんせいは こどもたちを こうえんで あるかせる。

## 言う
確認済み: `いわなかった / いえる / いえば / いおう / いわせる`

- なかった: きのうは その ことを だれにも いわなかった。
- 可能: この ことばなら、すぐ いえる。
- ば: ほんとうの ことを いえば、みんな わかります。
- 意向: せんせいに「ありがとう」と いおう。
- 使役: せんせいは がくせいに なまえを いわせる。

国立国語研究所『日本語日常会話コーパス』の集計にも `言える` の実使用が確認できる。

## 動く
確認済み: `うごかなかった / うごける / うごけば / うごこう / うごかせる`

- なかった: でんちが なくて、おもちゃが うごかなかった。
- 可能: この ロボットは みぎにも ひだりにも うごける。
- ば: きかいが うごけば、しごとを はじめられます。
- 意向: つぎの ばしょへ うごこう。
- 使役: せんせいは がくせいを まえへ うごかせる。

注意: `動かせる` は「動く」の使役形と「動かす」の可能形が同じ表面形になる。問題では主語・使役者・移動者が分かる文脈にする。

## 買う
確認済み: `かわなかった / かえる / かえば / かおう / かわせる`

- なかった: きのうは なにも かわなかった。
- 可能: この ねだんなら、わたしも かえる。
- ば: いま かえば、あした つかえます。
- 意向: きょうは やさいを かおう。
- 使役: ちちは むすこに じぶんで きっぷを かわせる。
